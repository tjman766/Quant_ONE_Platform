# v27.44 실행 오류 복구 + 모의 실계좌 주문 + 통합 리밸런싱 운용 정책 적용

## 1. 런처 오류 해결

기존 오류:

```text
'".venv\Scripts\activate.bat"'은(는) 내부 또는 외부 명령...
```

원인:
- `.venv`가 없거나 깨졌는데 배치파일이 `activate.bat` 호출에 의존함
- 현재 폴더 기준 실행 경로가 어긋나면 activate.bat를 찾지 못함

조치:
- `quant.bat`를 self-healing 방식으로 교체
- `.venv\Scripts\python.exe`가 없으면 `.venv`를 삭제 후 재생성
- `activate.bat`를 더 이상 호출하지 않음
- 모든 명령을 `.venv\Scripts\python.exe -m ...` 형태로 직접 실행
- `.env`가 없으면 `.env.example`에서 자동 생성

## 2. 계좌 주문 실행 기본 상태

주문 실행은 상단 모의/실전 전환값만 따릅니다.

```env
KIWOOM_ACTIVE_PROFILE=MOCK
```

- `MOCK`: 키움 모의투자 계좌에 주문 API 전송
- `LIVE`: 키움 실전투자 계좌에 주문 API 전송

## 3. 통합 운용 개념

요청한 개념을 하나의 운용 흐름으로 합쳤습니다.

1. 백테스트
2. 모의투자 계좌 주문
3. 결과 리포트
4. 실전투자 계좌 주문
5. 결과 리포트
6. 월/분기/반기/연간/시즌제 리밸런싱
7. 상위 N개 편입
8. 검증된 전략만 유지
9. 투자비중 0.90~0.95, 현금버퍼 5~10%
10. 급변장 신규매수 차단/축소

## 5. 적용 파일

| 파일 | 변경 내용 |
|---|---|
| `quant.bat` | `.venv` 자동 생성/복구, activate.bat 의존 제거 |
| `quant_debug.bat` | 진단 정보 확대 |
| `.env` | 기본 환경설정 포함 |
| `.env.example` | 리밸런싱/계좌주문/현금버퍼 설정 항목 추가 |
| `app/services/settings.py` | 운용 정책 환경변수 로드 |

| `app/services/order_executor.py` | `KIWOOM_ACTIVE_PROFILE` 기준 모의/실전 계좌 주문 전송 |
| `app/core/realtime_state.py` | 자동매매 메뉴용 정책/전략비교/매수매도 기준 데이터 제공 |

| `app/static/app.js` | 자동매매 정책/전략비교/계좌주문 상태 표 렌더링 추가 |
