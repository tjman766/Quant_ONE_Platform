# v27.44 모의 실계좌 주문 + 전략 비교/선택 + 리밸런싱 통합

## 핵심 변경

1. 별도 주문 실행 차단 환경변수와 관련 분기 제거
2. 상단 모의/실전 전환값 `KIWOOM_ACTIVE_PROFILE`만으로 주문 계좌 결정
3. `MOCK`이면 키움 모의투자 계좌에 주문 API 전송
4. `LIVE`이면 키움 실전투자 계좌에 동일 구조로 주문 API 전송
5. 자동매매 메뉴에 `내 전략` / `4대 퀀트 전략(기본)` 비교표 추가
6. 자동매매 메뉴에 전략 선택 카드 추가
7. 자동매매 메뉴에 운용 상태·리밸런싱·결과 리포트 통합표 추가

## 주문 실행 정책

| 상태 | 의미 |
|---|---|
| `KIWOOM_ACTIVE_PROFILE=MOCK` | 키움 모의투자 계좌에 kt10000/kt10001 주문 API 전송 |
| `KIWOOM_ACTIVE_PROFILE=LIVE` | 키움 실전투자 계좌에 kt10000/kt10001 주문 API 전송 |

모의와 실전은 프로그램 구조가 동일하며, 사용자가 최상단 모의/실전 전환 버튼으로 수동 조정합니다.

## 리밸런싱 설명

리밸런싱은 보유 종목과 비중을 정해진 주기 또는 조건에 맞춰 다시 맞추는 작업입니다.
예를 들어 TOP 20 전략이라면 현재 보유 종목이 TOP 20에서 밀려났거나, 점수가 크게 떨어졌거나, 비중이 너무 커졌거나, 손절 조건이 발생했을 때 매도/교체합니다.

지원 주기:

- 월간
- 분기
- 반기
- 연간
- 시즌제

## 현금버퍼 설명

현금버퍼는 총자산을 100% 전부 매수하지 않고 5~10%를 현금으로 남기는 방식입니다.
프로그램 기본값은 총자산의 90~95%까지만 투자하는 구조입니다.

현금버퍼 목적:

- 주문 실패/미체결 대응
- 급락장 추가 손실 방어
- 리밸런싱 시 교체 매수 여력 확보
- 예상치 못한 변동성 대응

## 자동매매 메뉴 적용 위치

| 메뉴 표 | 반영 내용 |
|---|---|
| 전략 선택 | `내 전략` / `4대 퀀트 전략(기본)` 선택 카드 |
| 전략 비교표 | 두 전략의 상위 N, 리밸런싱, 현금버퍼, 손절, 익절, 시장필터, 리스크관리, 급변장 대응, 전략점수 비교 |
| 운용 상태 통합표 | 백테스트 → 모의투자 계좌 주문 → 결과 리포트 / 백테스트 → 실전투자 계좌 주문 → 결과 리포트 |
| 계좌 주문 실행 상태 | 현재 MOCK/LIVE에 따라 어느 계좌로 주문 API가 나가는지 표시 |
| 통합 운용 정책 적용 현황 | 리밸런싱, 상위 N, 현금버퍼, 결과 리포트, 급변장 방어 표시 |
